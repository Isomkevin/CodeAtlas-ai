# Personas

## Staff Engineer

Needs:

- Understand large systems quickly
- Reduce onboarding time
- Review architectural changes

Pain Points:

- Stale documentation
- Hidden dependencies
- Unknown side effects

---

## Solutions Architect

Needs:

- Design scalable systems
- Validate implementations
- Communicate architecture

Pain Points:

- Diagrams become outdated
- Teams implement different designs

---

## Engineering Manager

Needs:

- System visibility
- Risk assessment
- Architectural governance

Pain Points:

- Cannot measure architectural health

---

## AI Coding Agent

Needs:

- Structured architectural context
- Constraints
- Design decisions

Pain Points:

- Limited context windows
- Missing architectural intent
